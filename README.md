# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.23.0+33: исправлено ошибочное перекрытие дверей стенами из-за вырожденных граней. Радиатор хранит количество секций и ширину секции: общая ширина рассчитывается сразу и используется на плане, в 3D, развёртке стены и прогулке. Доступны 1–40 секций, начальная настройка — 12 × 80 мм. Новый JSON v19 читает проекты v1–18. Сохранены управление слоями в прогулке, пакетная отрисовка 3D, стеклянные двери, текстуры, кондиционеры, этажи и лестницы.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
