# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.21.1+31: ускорены Web 3D и прогулка. Непрозрачная геометрия рисуется пакетами треугольников, маски инженерных сетей вычисляются без тяжёлых операций CanvasKit, параметры камеры и геометрии кэшируются. В контрольном сценарии вращения на одной машине получено ускорение 3,8× для комнаты и 8,8× для дома; это сравнительный замер, не обещание FPS. Сохранены правильные перекрытия стенами, стекло, текстуры и отдельный режим просвечивания, трубы/радиаторы в прогулке, кондиционеры, загрузчик, этажи и лестницы.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
