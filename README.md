# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.22.0+32: в прогулке появилась кнопка «Слои коммуникаций». Электрику, водопровод и отопление можно скрывать независимо, оставить одну систему или показать все. Выбор сохраняется в проекте и действует также в редакторе и на других этажах; мебель и включённость света сохраняются. Скрытие электрики убирает провода, розетки, выключатели, светильники и щит. Панель доступна на компьютере и телефоне. Сохранены ускоренный 3D, правильные перекрытия стенами, стекло, текстуры, кондиционеры, загрузчик, этажи и лестницы.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
