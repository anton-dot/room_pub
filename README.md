# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.29.0+40: версия и автор `anton-dot` видны рядом с RoomVibe на главном экране и при загрузке. Web проверяет обновления автоматически и по кнопке, предлагает перезагрузку или отложить. Перед переходом сохраняются проекты; при ошибке записи или пропавшей сети перезагрузка отменяется. Старый код обходится URL сборки без очистки проектов и фотографий. Сохраняются свободные проёмы на всю стену, редактируемые Г-, П- и Т-образные комнаты. Формат проекта JSON v23, импорт v1–22.

Доступны автоматические соединения электроприборов одним кабелем с редактируемыми точками XYZ, каталог из 84 типов, полотенцесушители, подложка плана с масштабом, измерения, перегородки, группы и материалы пола/мебели. JSON v23, импорт v1–22. Автоматическая прокладка кабеля пока в пределах одного этажа.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
