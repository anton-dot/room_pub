# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.24.0+34: цвет пола задаётся для каждой комнаты через общую палитру и HEX независимо от покрытия. Откройте свойства комнаты → «Пол» → «Цвет пола»; «Цвет материала» возвращает исходный оттенок. Цвет виден на плане, в карточке проекта, 3D и прогулке, сохраняется в файле проекта и истории. JSON v20 читает проекты v1–19. Сохранены исправление перекрытия дверей стенами, секционные радиаторы, управление слоями в прогулке, пакетная отрисовка 3D, стеклянные двери, текстуры, кондиционеры, этажи и лестницы.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
