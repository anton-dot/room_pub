# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.36.0+47: параметры комнаты справа собраны в раскрывающиеся разделы «Размеры и положение», «Пол», «Стены», «Потолок», «Фотографии». У разделов есть пояснения; пол раскрыт изначально, чтобы легко найти покрытие, цвет и текстуры. «Наливной пол» и «Подвесной потолок» доступны в соответствующих разделах. Настройки вида отделены от свойств комнаты; диалог свойств тоже разбит заголовками. Формат проекта JSON v24, импорт v1–23.

Доступны автоматические соединения электроприборов одним кабелем с редактируемыми точками XYZ, каталог из 84 типов, полотенцесушители, подложка плана с масштабом, измерения, перегородки, группы и материалы пола/мебели. JSON v24, импорт v1–23. Автоматическая прокладка кабеля пока в пределах одного этажа.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
