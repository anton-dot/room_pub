# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.25.0+35: каталог расширен с 42 до 84 типов; добавлены горизонтальный и вертикальный полотенцесушители в отоплении. Доступны подложка плана с масштабом по двум точкам, точные размерные линии, свободные и стеклянные перегородки с дверями, выбор нескольких предметов, группы, выравнивание и блокировка положения. Материалы пола и мебели: дерево, плитка, камень, ткань, металл или фотография; масштаб, поворот, отдельный материал фасадов/верха, копирование материалов. Изменения сохраняются в JSON v21 с импортом v1–20 и историей. Во вкладке «Комнаты» находятся подложка, линейка и перегородка, в свойствах пола и предметов — материалы. Перегородки пока не разделяют помещение на новые комнаты автоматически.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
