# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.26.0+36: автоматическое соединение электроприборов одним кабелем. В свойствах щитка, коробки или розетки нажмите «Соединить кабелем», выберите второй прибор и прокладку у потолка/пола. Трасса проходит по стенам, в том числе между соседними комнатами одного этажа. Можно вставлять и удалять точки, задавать XYZ, опускать отдельный участок с вертикальными переходами, двигать узлы в 2D и 3D. Концы следуют за приборами, отредактированная середина сохраняется. JSON v22, импорт v1–21, история, копирование и сохранение связей. Межэтажная автоматическая трассировка пока не поддерживается. Каталог из 84 типов, полотенцесушители, подложка плана, измерения, перегородки, группы и материалы пола/мебели сохранены.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
