# RoomVibe

Web-приложение для проектирования квартиры в 2D и 3D: [room.kurakin.pro](https://room.kurakin.pro/).

Версия 1.26.1+37: исправлены разрывы плинтуса на углах, включая наклонные стены. Участки соединяются полным профилем с учётом толщины обеих стен и плинтуса; общая геометрия используется в 2D, 3D, прогулке и развёртках. Дверные проёмы остаются свободными. Исправление применяется к существующим проектам автоматически.

Доступны автоматические соединения электроприборов одним кабелем с редактируемыми точками XYZ, каталог из 84 типов, полотенцесушители, подложка плана с масштабом, измерения, перегородки, группы и материалы пола/мебели. JSON v22, импорт v1–21. Автоматическая прокладка кабеля пока в пределах одного этажа.

Этот репозиторий содержит готовую Web-сборку Flutter для GitHub Pages. Файл `CNAME` сохраняет собственный домен, `.nojekyll` позволяет раздавать все ресурсы приложения.

Проекты и фотографии хранятся локально в браузере. Для резервной копии или переноса используйте экспорт/импорт JSON в приложении.
